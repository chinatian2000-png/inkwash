Procedural Chinese ink-wash landscape

Fractal noise + contour extraction. No AI, no model, no network. Same seed → same image, always.

Every pixel is computed in your browser from a seeded PRNG, value-noise fBm and ridged-multifractal height profiles. There is no image library, no GPU shader, no server call — view source and read src/inkwash.js. Re-render the same seed and you get a byte-identical image (the PNG encoder is deterministic too).
